# Gestionale I-Energy

App web (PWA) per commesse, planning, personale, azienda, documentale, scadenzario e ore.

- **Accesso:** Google, tramite Supabase.
- **Dati:** Supabase (tabella `docs`), aggiornamenti in tempo reale.
- **File:** Google Drive, tramite il backend Apps Script (`apps-script/Code.gs`), che riconosce l'accesso Supabase.
- `privacy.html`: informativa privacy richiesta da Google.
